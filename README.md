# yt-factory-site

Public privacy policy and terms pages for the yt-factory Google Cloud project (required by the OAuth consent screen and the YouTube API compliance audit).

## Publish

1. Replace every `ganeshshinde7111@gmail.com` with the channel's contact address.
2. **Settings → Pages → Build and deployment → Deploy from a branch → `main` / root → Save.**
3. Pages are served at `https://ganeshshinde7111.github.io/yt-factory-site/`:
   - Privacy: `/yt-factory-site/privacy.html`
   - Terms: `/yt-factory-site/terms.html`
4. Use those two URLs on the Google Cloud OAuth consent screen and in the audit form.
